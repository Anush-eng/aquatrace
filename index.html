About AquaTrace Project

AquaTrace is a coastal water quality monitoring platform engineered using an Arduino Uno microcontroller paired with four core sensors: pH Sensor, TDS (Total Dissolved Solids) Sensor, Turbidity Sensor, and a DS18B20 Waterproof Temperature Sensor, alongside an I2C 20×4 LCD Character Display. The system implements multi-sensor data fusion, deterministic anomaly detection, sensor health monitoring, and short-term predictive analysis for transparent environmental protection.
